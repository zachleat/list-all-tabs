# List All Tabs

A Firefox extension that lists every open tab across all windows, groups duplicates and busy hosts (respecting Multi-Account Containers), and lets you jump to or close tabs individually or by host.

- Firefox Add-ons: https://addons.mozilla.org/en-US/firefox/addon/list-all-tabs-updated/
- Source: https://github.com/zachleat/list-all-tabs

## Developer Notes

- `npx web-ext build --overwrite-dest` will build a zip file to upload
- `about:debugging#/runtime/this-firefox` and choose the `manifest.json`
